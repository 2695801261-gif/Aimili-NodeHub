# Aimili NodeHub

个人节点采集、验证与分级项目，面向 Mihomo / FlClash。

## 当前阶段

本仓库先接入经过 MIT 许可的 [FreeNodes](https://github.com/nostalume/FreeNodes) 作为采集、去重、Mihomo 实际连通性验证和订阅生成底座。上游固定到提交 `5a4f4ecf8c06b49b503046179d10933a6a63ef69`，避免上游变化导致流程无意漂移。

**重要：当前第一版只发布“已通过上游能力验证的通用节点池”，尚未把节点标记为住宅 IP 或低风险机房 IP。** 仅凭节点名称、来源标签、服务器地址国家或单一 IP 数据库，不能证明出口 IP 是住宅网络。后续分类器必须通过代理真实出口检测，并保留 ASN、ISP、网络类型和风险证据；证据不足的节点进入隔离区，不进入分类订阅。

## 自动运行

- GitHub Actions：每 6 小时定时运行，也可在 Actions 页面手动运行。
- 使用公开仓库的 GitHub-hosted runner。
- 不需要 VPS、Cloudflare Worker、KV、域名或额外 API 密钥。
- 运行成功且输出有变化时，自动提交更新 `nodes/`。
- 上游采集/验证失败时，不覆盖本仓库上一次成功生成的订阅。

## 订阅

首版验证通过后，将生成文件放在 `nodes/`。在分类模块验收之前，不会把通用节点冒充成美国住宅、其他国家住宅或低风险机房节点。

## 安全与边界

免费公开节点由未知第三方运营。不要用于银行、支付、主邮箱、账号恢复或其他敏感流量；节点可能记录流量元数据、随时失效或被滥用。公开仓库的订阅内容任何人都能读取。

## 开源基础

- [FreeNodes](https://github.com/nostalume/FreeNodes) — MIT；用于公开订阅发现、节点去重、Mihomo 连通能力验证及订阅生成。
- 本仓库不直接复制其源代码；工作流在运行时按固定提交检出上游项目。
