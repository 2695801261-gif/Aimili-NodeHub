# 节点分类与证据规则

目标输出分为三类：

1. `us-residential`：真实代理出口位于美国，且有足够证据支持住宅/家宽网络属性。
2. `other-residential`：真实代理出口位于美国以外，且有足够证据支持住宅/家宽网络属性。
3. `low-risk-datacenter`：真实代理出口属于数据中心网络，并通过多项风险检查；“低风险”仅表示相对筛选结果，不代表安全保证。

## 必须遵守

- 必须先通过代理连接外部检测端点，读取代理实际出口 IP；不能用节点配置中的 server 地址代替出口 IP。
- 国家归属使用出口 IP 的地理位置证据。
- 网络类型至少结合 ASN、ISP/组织名称、网络类型数据库等独立证据；单一标签不够。
- 住宅类要求多来源证据相互支持。证据冲突、缺失或无法验证时标记为 `unknown`，不发布到住宅订阅。
- 数据中心类也需要独立证据；风险检查不通过或证据不足时隔离。
- 禁止根据节点名称中的 US、Residential、Home、ISP 等字样直接分类。
- 保存检测时间、出口 IP、国家、ASN、ISP、来源及判断理由，便于复核。
- 订阅发布前必须验证格式、非空、节点实际可连接；分类失败不能影响保留上一版有效订阅。

## 发布状态

当前阶段尚未启用三类分类订阅。只有分类器、证据来源和测试用例完成后才开放对应文件，避免把未经验证的节点误标成住宅或低风险节点。
